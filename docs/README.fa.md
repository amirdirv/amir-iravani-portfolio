# راهنمای فارسی

راهنمای کوتاه برای به‌روزرسانی روزمرهٔ سایت. جزئیات فنی کامل در [ARCHITECTURE.md](ARCHITECTURE.md) است.

## اجرای سایت روی کامپیوتر

</div>

```bash
npm install
npm start
```

<div dir="rtl">

بعد آدرس `http://localhost:4200` را باز کنید.

## تغییر محتوا

همهٔ متن‌های سایت فقط در دو فایل هستند:

| فایل | چه چیزی دارد |
| --- | --- |
| `src/app/data/profile.ts` | سوابق کاری، پروژه‌ها، مهارت‌ها، تحصیلات، زبان‌ها و لینک‌ها |
| `src/app/data/ui.ts` | همهٔ تیترها، دکمه‌ها و جمله‌های رابط کاربری |

هر متن سه نسخه دارد: `en` (انگلیسی)، `it` (ایتالیایی) و `fa` (فارسی). هر سه را پر کنید. اگر یکی جا بیفتد، دستور `npm test` دقیقاً می‌گوید کدام.

### اضافه‌کردن یک کار جدید

یک مورد جدید **بالای** فهرست `EXPERIENCES` در `profile.ts` اضافه کنید (نمونهٔ کامل در [CONTENT.md](CONTENT.md) است). برای کار فعلی `end` نگذارید و به کار قبلی `end` بدهید. تایم‌لاین گیت، گراف مهارت‌ها، ترمینال و رزومهٔ چاپی خودکار به‌روز می‌شوند.

### عوض‌کردن عکس

عکس مربعی جدید را به این صورت بدهید:

</div>

```bash
python tools/generate-assets.py path/to/photo.png
```

<div dir="rtl">

## انتشار

هر بار که روی شاخهٔ `main` پوش کنید، GitHub Actions سایت را تست، بیلد و روی GitHub Pages منتشر می‌کند.

**فقط یک بار لازم است:** در ریپازیتوری به **Settings → Pages** بروید و در قسمت **Source** گزینهٔ **GitHub Actions** را انتخاب کنید.

</div>

```bash
git add -A
git commit -m "content: add new role"
git push
```
